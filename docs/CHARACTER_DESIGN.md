# ELEMENT 118 キャラクターデザイン基準

## 基準画像

**`art/reference/character-design-reference.png`** が正式なキャラクターデザイン基準です。

- 受け取ったPNGを1バイトも変えずに保存しています（1536×1024、RGB）。
- SHA-256：`2b09ca700caeadd5911caccf699a352c03318cd6a7a504a56fe78011aec2eeba`
- スクリーンショット化・JPEG化・縮小・再圧縮・上書きは禁止です。`npm run validate`（ビルドのたびに実行）がハッシュを照合し、1バイトでも変わればビルドが止まります。
- この画像は **見本** です。ゲームには読み込みません（`public/` に置かない、コードから参照しない）。これも `npm run validate` が確認します。

## 基準画像から切り出さない

基準画像をそのままゲーム用スプライトとして切り出すことはしません。
実装用のスプライトは、キャラクターごとに **厳密なグリッドで描き直した個別PNG** を用意し、順に置き換えます。

- 描き直すときは基準画像の顔・服装・色・シルエットに合わせる。
- 1キャラ＝1枚のPNG（`public/assets/sprites/<キー>.png`）。
- コマは下の「グリッド規格」に合わせて、1ドットのずれもなく並べる。
- 描き直したPNGの元データ（レイヤー付きのファイルなど）は `art/sprites-src/` に置く。

今ゲームに入っている人物スプライトは、前の版のシート（`art/source/character-sheet.png`）から `scripts/extract-sprites.py` で切り出した **暫定版** です。描き直し版ができたものから差し替え、切り出しスクリプトの該当部分は外していきます。

## キャラクター別の基準

### C　カーボン（主人公・炭素）

この3つは変えない：

1. **恥ずかしがり屋で、お面をつけている**（白いキツネ風のお面、橙の模様、横に橙の留め具）
2. **「C」と「6」が象徴**（お面の中央に大きく「C」、右下に小さく「6」＝原子番号）
3. **最初は未完成感がある**（つぎはぎの薄いベージュのマント、使い込んだ茶色の肩かけカバン、古い茶色のブーツ。装備は冒険とともに少しずつ完成させる）

そのほか：茶色のぼさぼさ頭で、左上に橙の房。ベージュのシャツ、茶色の短パン、腰に青い結晶の飾り。後ろ姿は茶色の髪だけが見える。

### H　ハイド（水素）
青い髪にアホ毛。頭に茶色の縁のゴーグル。青い目。白と青の軽装。

### O　オキシ（酸素）
ピンクの髪で、お団子つきのツインテール。赤みの目。赤と白の服。

### Na　ナト（今後の仲間）
橙〜金のつんつん頭に、大きな黄色いゴーグル。橙の服。

### Cl　クロル（今後の仲間）
黄緑の長い髪。緑の服。

### Fe　フェルム（今後の仲間）
紫がかった灰色の髪。銀と青の鎧。きりっとした顔。

### 表情（会話用）
通常・笑顔・目を閉じて笑う・おどろく・考える・困る・てれる・泣く・ひらめき の9種類。カーボンはお面をつけたまま、目元とお面のずれ方、頬の赤みで気持ちを表す。

## グリッド規格（描き直し版）

すべて背景は透明。拡大・縮小はゲーム側で整数倍のみ（ぼかさない）。

| 種類 | 1コマ | 行 | 列 |
| --- | --- | --- | --- |
| 主人公・仲間（カーボン、ハイド、オキシ、ナト、クロル、フェルム） | 32×32 | 0 下、1 上、2 右（左は反転）。8方向にするときは 3 右下、4 右上 を足す | 0-1 待機、2-5 歩行、6-8 攻撃、9 回避、10 ガード、11 被ダメージ、12-13 BOND |
| 村の住民 | 32×32 | 0 下、1 上、2 右 | 0-1 待機、2-3 歩行、4-5 会話 |
| 会話の顔 | 32×32で描く | 1行 | 表情を上の9種類の順に並べる。ゲームでは6倍（192×192）で表示 |

足元の位置はすべてのコマで同じ高さにそろえる（下から2ドット目が足の裏）。
