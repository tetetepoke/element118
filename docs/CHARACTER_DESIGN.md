## 基準画像を下絵にして、32×32のマスに描き直す

基準画像をそのまま切り抜いて貼ることはしません。各ポーズを **下絵** にして、32×32のマスへ描き直します（2026-11-25 決定）。

- 基準画像は読むだけ（`scripts/trace-*.py` だけが開いてよい。ほかから参照するとビルドが止まる）。
- 全コマ同じ倍率でマスに合わせる → 決まった色数に整理 → 輪郭を1ドットで引き直す → ゴミ点を消す → 足元をそろえる。
- お面の「C」「6」のような文字は、縮めるとつぶれるので1ドットずつ描く。
- 基準画像にない向き・動き（後ろ向き、被ダメージ、BOND）は、基準画像のパーツから組み立てるか、描き足す。
- 1キャラ＝1枚のPNG（`public/assets/sprites/<キー>.png`）。拡大確認用は `art/sprites-src/`。

今のハイド・オキシ・村人は、前の版のシートから切り出した **暫定版** です。順に描き直します。

## キャラクター別の基準

### C　カーボン（主人公・炭素）

この3つは変えない：

1. **恥ずかしがり屋で、お面をつけている**（白いキツネ風のお面、橙の模様、横に橙の留め具）。ふだんは顔を出して歩き、**人（仲間以外）や敵が近づくとお面をつける**（ゲーム内の歩く絵は基準画像の待機〜ガードの行のちびキャラに合わせる）
2. **「C」と「6」が象徴**（お面の中央に大きく「C」、右下に小さく「6」＝原子番号）
3. **最初は未完成感がある**（つぎはぎの薄いベージュのマント、使い込んだ茶色の肩かけカバン、古い茶色のブーツ。装備は冒険とともに少しずつ完成させる）

そのほか：茶色のぼさぼさ頭で、左上に橙の房。ベージュのシャツ、茶色の短パン、腰に青い結晶の飾り。後ろ姿は茶色の髪だけが見える。

### H　ハイド（水素）
青い髪にアホ毛。頭に茶色の縁のゴーグル。青い目。白と青の軽装。

### O　オキシ（酸素）
ピンクの髪で、お団子つきのツインテール。赤みの目。赤と白の服。

### Na　ナト（今後の仲間）
橙〜金のつんつん頭に、大きな黄色いゴーグル。橙の服。

### Cl　クロル（今後の仲間）
黄緑の長い髪。緑の服。

### Fe　フェルム（今後の仲間）
紫がかった灰色の髪。銀と青の鎧。きりっとした顔。

### Si　シリカ（ケイ素・ステージ2の仲間）
白〜銀の髪に水色の結晶の飾り。紫のマフラー／ケープ、白い服、黄色のブーツ。論理的・観察好き・慎重で、少し理屈っぽい。

### SiC FORM（カーボン＋シリカ）
カーボンのシルエットのまま、白〜水色の結晶のトゲ、紫のマフラー、銀の装甲。**C／6のお面は額にずらしてつけたまま残す**（小さいスプライトでは額のお面とCを1ドットずつ描く）。H FORM（C＋H）・O FORM（C＋O）も基準画像にあるが、まだ登場しない。

## グリッド規格（描き直し版）

すべて背景は透明。拡大・縮小はゲーム側で整数倍のみ（ぼかさない）。

| 種類 | 1コマ | 行 | 列 |
| --- | --- | --- | --- |
| 主人公・仲間（カーボン、ハイド、オキシ、ナト、クロル、フェルム） | 32×32 | 0 下、1 上、2 右、3 左（左を別に描くと文字や左右差が反転しない。なければ右を反転）。カーボンは顔出し `carbon` とお面 `carbonm` の2枚 | 0-1 待機、2-5 歩行、6-8 攻撃、9 回避、10 ガード、11 被ダメージ、12-13 BOND |
| 村の住民 | 32×32 | 0 下、1 上、2 右 | 0-1 待機、2-3 歩行、4-5 会話 |
| 会話の顔 | 32×32で描く | 1行 | 表情を上の9種類の順に並べる。ゲームでは6倍（192×192）で表示 |

足元の位置はすべてのコマで同じ高さにそろえる（下から2ドット目が足の裏）。
