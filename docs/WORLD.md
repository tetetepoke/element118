# ELEMENT 118 — WORLD / STORY

## 世界
物語の舞台には「アトミア」と呼ばれる地下都市が存在する。

これは空が見える巨大洞窟ではない。完全な地下世界。
地下から外の光は全く見えない。空も太陽も直接見ることはできない。

## プロローグ
物語は地下のゴミ処理場から始まる。
そこで意識を失った少年が発見される。

少年は Carbon / C / 原子番号6、カーボン。
なぜそこにいるのか。どこから来たのか。本人にも分からない。

住民の反応には奇妙な言葉が混じる。

「また降ってきた。」

「また」とは何なのか。どこから「降ってきた」のか。この時点では説明しない。

## 地下都市アトミア
アトミアには地上の太陽光が直接届かない。
それにもかかわらず、都市には光が存在する。地下の人々はその光の中で生活している。

その中心となるのが「青く光る巨大な構造」である。

## 青い光の正体
最初は巨大な青い結晶のように見える。しかし、本当は単なる鉱物ではない。
正体は「巨大な世界樹の根の一部分」である。

地下都市から見えているのは世界樹全体ではない。
地下深くまで伸びた根の、ごく一部が露出しているだけ。

## 天晶脈
青く光る世界樹の根は「天晶脈」と呼ばれる。
天晶脈は地上で取り込まれた太陽光を地下へ伝えている。イメージとしては光ファイバーに近い。

```
地上 → 世界樹 → 根 → 天晶脈 → 地下都市
```

そのため地下から太陽は見えない。外の光も直接見えない。それでも地下には青い光が存在する。

## 地下の太陽
アトミアの住民にとって天晶脈の光は、生活を支える「太陽」のような存在。
光は、都市・生態系・植物・生活・移動などと関係している。

## 世界樹の起源
世界樹は最初から存在していたわけではない。
遠い昔、「誰かが一つの種子を植えた。」
その種が長い年月をかけて成長し、巨大な木となり、その根は地下深くまで伸びた。

ただし「誰が種を植えたのか」は序盤では明かさない。長期的な物語の謎とする。

## 上へ続くヒント
カーボンは地下世界を探索する中で、青い天晶脈がただ光っているだけではないことに気づいていく。
根はどこかへ続いている。その方向は「上」。
天晶脈を追うことが、地下から地上へ向かうための重要な手掛かりになる。

## 重要な演出ルール
序盤から「これは世界樹です」「光ファイバーのように太陽光を運んでいます」と全部説明しない。
最初は「青く光る謎の構造」として見せる。

プレイヤーに、
- 「これは結晶なのか？」
- 「なぜ光っている？」
- 「どこまで続いている？」
- 「上には何がある？」

という疑問を持たせる。

少しずつ、植物のような形・根のような分岐・古い記録・地上との関係・光の流れなどのヒントを見せる。

## 科学とファンタジー
ELEMENT 118では科学を重要視する。ただし世界樹など、現実には存在しない設定も登場する。
その場合、「現実の科学的事実」と「ELEMENT 118世界の架空設定」を混同しない。
世界樹が光を地下へ運ぶ性質は、ELEMENT 118世界独自の生物学的性質として扱う。

## 元素と世界
カーボンは旅の中でさまざまな元素と出会う。
元素は単なる収集物ではない。それぞれ違う性質を持つ存在。違うからこそ、それぞれに役割がある。

そして必要なとき、BONDする。必要がなくなれば、BREAKする。

## 物語テーマ
物語全体には「違っていていい」という考え方を持たせる。
118の元素は、それぞれ性質が違う。すべてが同じになる必要はない。

そして「つながる時だけ、つながればいい。」という考え方をBOND/BREAKと物語の両方につなげる。

ただし、このテーマを台詞で説明しすぎない。プレイヤー自身が物語を通して感じられるようにする。

## 長期的な謎
序盤ですべて答えを出さない。

重要な謎：
- カーボンはどこから来たのか
- なぜゴミ処理場に落ちていたのか
- 「また降ってきた」とは何を意味するのか
- 地上には何があるのか
- なぜ地下都市が存在するのか
- 天晶脈とは本当は何なのか
- 世界樹はなぜ光を運べるのか
- 誰が世界樹の種を植えたのか
- 118元素と世界の過去に何があったのか

これらを探索とストーリーの進行によって少しずつ明らかにする。

## ストーリーの見せ方
長い説明文だけで世界設定を伝えない。
景色・NPC・地下都市・廃墟・元素・天晶脈・古い記録・環境変化・BOND/BREAKなどを利用する。
プレイヤー自身が「もしかして……」と気づく瞬間を大切にする。

## 最重要
ELEMENT 118は「元素を覚えるためだけの教育ゲーム」ではない。
まず「続きが知りたくなる冒険ゲーム」であること。
その冒険そのものに元素の性質を組み込み、遊んだ結果として科学への興味が生まれるゲームを目指す。
