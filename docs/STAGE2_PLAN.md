# ステージ2「珪晶の谷」実装計画

## 全体テーマ（今後の全ストーリーの中心）
「118の違いを、一つにするのではなく、必要な時につなぐ」。
THE BREAKの本当の問題は元素が消えたことではなく、元素同士のつながりが失われたこと。
ラスボス「ゼロ」は「すべてが単独なら世界は壊れない」と考える。最終決戦でカーボンは118元素を一つにしようとして BOND ERROR → 「全部を一つにすることが、つながることではない」と理解し、自分自身をBREAK。最後の言葉は「違ってていい。」「つながる時だけ、つながればいい。」
ステージ2はこのテーマの最初の一歩：**BONDで強くなる → BREAKで道が開ける**。

## 守ること
- Rainなど他プロジェクトには触れない。作業は element118 リポジトリの中だけ。
- ステージ1のマップ・台詞・仕掛けは変えない（`World` シーンはそのまま。ステージ2は別シーン `Valley`）。
- セーブは同じキー（`element118.save.slot1`）。版を1→2に上げ、足りない項目だけ補う。ステージ1のセーブはそのまま続きから遊べる。

- 図鑑では「本物の科学」と「ゲーム上の能力（フィクション）」を必ず分けて書く。

## 新しい仕組み
- **CHARACTER BOND**：BONDボタン →「仲間とBOND」でカーボンと仲間を選ぶ。C＋Si → SiC → SILICON CARBIDE → NEW FORM DISCOVERED。C＋H、C＋Oは「まだ分からない」。
- **SiC FORM**（ゲーム上の能力）：HARD BREAK（硬い岩を壊す）、HEAT RESIST（熱い地帯を進める）。狭い場所と2人用の装置は使えない。
- **BREAK**：SiC FORM → C＋Si。シリカが横に現れ、「交代」で操作キャラを切り替えられる。もう一度BONDするときは2人が近くにいる必要がある。
- **2人同時スイッチ**：カーボンとシリカがそれぞれ別のスイッチに乗ると扉が開く。
- **パーティ**：カーボン固定＋同行2人。元素碑で入れ替え。
- **UNKNOWN PROPERTY**：今の能力では動かない装置（電気が必要）。調べるとマップに「？」が残る。Cuを見つけたら戻って解ける。

## 物語の流れ
1. 水が戻ったカーボ村のはずれ。研究者が川で見つけた結晶片の話 → 珪晶の谷へ。
2. 巨大な岩壁で道が塞がれている（攻撃してもびくともしない）。
3. 別ルートでシリカ（Si/14）と出会う → NEW ELEMENT。シリカだけでも岩壁は壊せない。
4. 古代研究所の記録で「C ＋ Si」のヒント → CHARACTER BOND → SiC FORM → HARD BREAKで岩壁を突破。
5. 熱い結晶地帯をHEAT RESISTで進む →「BONDすれば強くなる」と思わせる。
6. 狭い裂け目でSiC FORMのままでは進めない → BREAK。シリカ「強くなるだけが、BONDじゃない。」「離れた方がいい時もある。」
7. 後半：BOND → BREAK → BOND → BREAK（硬い岩、2人スイッチ、熱い地帯、狭い道）。途中に電気の装置（UNKNOWN PROPERTY）。
8. ボス「クリスタル・ブレイカー」：①SiC FORMのHARD BREAKで外殻を破る ②HEAT RESISTで熱い内部へ ③左右の制御装置をBREAKした2人で同時に作動 → 停止。
9. ボス後の会話 → シリカ正式加入 → 周期表（H・C・O・Siが点灯、残りは暗い、118）→ 夜、遠くの古代施設に青白い電気（UNKNOWN ENERGY）→ 次の地域「雷導の街」、Cu。

## 科学とフィクションの分け方
- Si：原子番号14。炭素と同じく結合の手4本。地殻に酸素の次に多い。自然界では二酸化ケイ素（石英・砂）やケイ酸塩として存在。半導体の材料。
- SiC（炭化ケイ素）：SiとCが1:1。分子ではなく、原子が網目のようにどこまでもつながった「共有結合の結晶」。とても硬い（研磨剤）、高温に強い、パワー半導体に使われる。工業的にはケイ砂と炭素を電気炉で約2000℃以上に加熱してつくる（SiO₂＋3C→SiC＋2CO）。
- SiC FORM：カーボンとシリカが力を合わせた架空の姿。SiCの「硬さ」「熱への強さ」をモチーフにしただけで、人がSiCになったり、熱い所を歩けるようになったりはしない。
- 結合パネル（つなぐ）の「手のルール」では、C＋Siはつながらない（SiCは小さな分子ではないため）。SiCはCHARACTER BONDだけで出てくる。Siのかけらは持ち運べない（シリカは仲間として登場）。
