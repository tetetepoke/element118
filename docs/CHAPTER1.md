## 複数の解き方（目的地だけが必須）
- **川**：①背の高い菌を「切る／たたく」で倒して橋にする　②上流の飛び石をジャンプ　③渡し守に話してハコビ（目のない大型生物）に乗る。泳ぐと流される。
- **枯れ根**：①切断工具（切る4以上：棒＋金属の刃など）　②大きな菌のかさを跳んで上の割れ目から回る　③SiC FORM（たたく9×0.5）
- **硬い岩**：SiC FORM、または「棒＋鉄鉱石」の重いハンマー（たたく8以上）

## 戻ると変わる所
- 廃棄区の奥の硬い岩（SiC で割れる）→ 中に古い殻と**白い仮面のかけら**（前にも誰かが降ってきた）、鉄鉱石。
- 都市北のひび割れた岩壁 → 鉱物層からの**近道**。
- 鉄鉱石：SiC で掘れる強さになっても、Fe（鉄）を理解していないと取れない。廃棄区の金属くずとさびた鉄板をスキャンすると Fe を理解 → 取れる → 重いハンマーが作れる。

### 物質相互作用
物はすべて `MaterialDef` を指す。性質は `hardness / toughness / conductivity / heatResistance / flammability / moisture / state / breakable / harvest / weak`。
道具・能力・素手はすべて `Power {cut, impact, pierce}` になり、`effect = max(力 × 物質の弱さ)` が `hardness` 以上なら成功。木だけ・岩だけの個別処理はない。
採取は `harvest.tier`（0：最初から／2：理解＋強さが必要）と `needKnown`（理解している元素）で決まる。

### 自由な道具づくり
決まったレシピはない。部品（アイテム）の「長さ・重さ・刃・とがり・平らな面・材料のかたさ・ねばり」から計算する。
- 棒＋重い石 → ハンマーのような道具（たたく4.5）
- 棒＋とがった石 → 槍のような道具（突く4.3）
- 棒＋金属の刃 → 斧のような切断工具（切る5.4）
- 棒＋石英のかけら → 切る7、棒＋鉄鉱石 → たたく8.6
名前はゲームが「形の説明」としてつけるだけ。部品の枠（`ToolDesign`）を増やせば、将来の3Dエディタにもつながる。

### 科学とフィクションの区別
スキャン画面と図鑑で、白い字＝本物の科学（例：石英は SiO₂、モース硬度7。鋼は鉄＋少量の炭素）、緑の字＝ゲームの設定。
BOND は「炭素は何とでも化合できる」ではなく、炭素の結合の多様さをモチーフにしたカーボン固有の能力として扱う。
硬さなどの数値はゲーム用のめやす（1〜10）。
