## 複数の解き方（目的地だけが必須）
- **川**：①背の高い菌を「切る／たたく」で倒して橋にする　②上流の飛び石をジャンプ　③渡し守に話してハコビ（目のない大型生物）に乗る。泳ぐと流される。
- **枯れ根**：①切断工具（切る4以上：棒＋金属の刃など）　②大きな菌のかさを跳んで上の割れ目から回る　③SiC FORM（たたく9×0.5）
- **硬い岩**：SiC FORM、または「棒＋鉄鉱石」の重いハンマー（たたく8以上）

## 戻ると変わる所
- 廃棄区の奥の硬い岩（SiC で割れる）→ 中に古い殻と**白い仮面のかけら**（前にも誰かが降ってきた）、鉄鉱石。
- 都市北のひび割れた岩壁 → 鉱物層からの**近道**。
- 鉄鉱石：SiC で掘れる強さになっても、Fe（鉄）を理解していないと取れない。廃棄区の金属くずとさびた鉄板をスキャンすると Fe を理解 → 取れる → 重いハンマーが作れる。

### 物質相互作用
物はすべて `MaterialDef` を指す。性質は `hardness / toughness / conductivity / heatResistance / flammability / moisture / state / breakable / harvest / weak`。
道具・能力・素手はすべて `Power {cut, impact, pierce}` になり、`effect = max(力 × 物質の弱さ)` が `hardness` 以上なら成功。木だけ・岩だけの個別処理はない。
採取は `harvest.tier`（0：最初から／2：理解＋強さが必要）と `needKnown`（理解している元素）で決まる。

### 自由な道具づくり
決まったレシピはない。部品（アイテム）の「長さ・重さ・刃・とがり・平らな面・材料のかたさ・ねばり」から計算する。
- 棒＋重い石 → ハンマーのような道具（たたく4.5）
- 棒＋とがった石 → 槍のような道具（突く4.3）
- 棒＋金属の刃 → 斧のような切断工具（切る5.4）
- 棒＋石英のかけら → 切る7、棒＋鉄鉱石 → たたく8.6
名前はゲームが「形の説明」としてつけるだけ。部品の枠（`ToolDesign`）を増やせば、将来の3Dエディタにもつながる。

### 科学とフィクションの区別
スキャン画面と図鑑で、白い字＝本物の科学（例：石英は SiO₂、モース硬度7。鋼は鉄＋少量の炭素）、緑の字＝ゲームの設定。
BOND は「炭素は何とでも化合できる」ではなく、炭素の結合の多様さをモチーフにしたカーボン固有の能力として扱う。
硬さなどの数値はゲーム用のめやす（1〜10）。

## 操作（InputManager）
すべての入力は `src3d/core/input.ts`（InputManager）で共通の入力に変換され、ゲームはそれだけを読む。
```
Touch / Keyboard+Mouse / Gamepad  →  InputManager  →  PlayerController / カメラ / ゲーム（Action）
```
共通入力：Move X/Y、Camera X/Y、Action（Jump / Interact / Bond / Break / Form / Scan / Menu / Map / Run / ToolPrev / ToolNext / ActionL / ActionR / StickL / StickR）。
設定は `src3d/core/inputConfig.ts`（デッドゾーン、感度、上下反転、キー割り当て、ゲームパッドの割り当て、ボタン表記）。
ゲーム内の「設定」から、タッチ・ゲームパッド・マウスのカメラ感度と上下反転を変えられる（`element118.ch1.input` に保存）。

| | iPhone | PC | ゲームパッド（Switch Proコン表記） |
| --- | --- | --- | --- |
| 移動（カメラの向き基準） | 左の指＝左スティック | WASD | 左スティック |
| カメラ（360°・上下は制限あり） | 右の指＝右スティック | マウスドラッグ | 右スティック |
| 走る | スティックを端まで／RUN | Shift | スティックを端まで |

| BREAK | BREAK ボタン | Q | Y |
| スキャン | SCAN | R | （画面のボタン／R キー） |

- 左右の指は同時に使える（マルチタッチ）。右スティックを離すと、カメラはその角度のまま止まる（自動で背中に回りこまない）。
- ゲームパッドは Web Gamepad API の「標準配置」を位置で読む（右＝A、下＝B、上＝X、左＝Y）。ボタン番号はゲームの処理に書かず、設定ファイルで Action に対応づけている。表記は機種名から Nintendo / Xbox / PlayStation を判定して切り替え。
- 最後に使った入力（タッチ／キーボード／ゲームパッド）で画面の表示が自動で切り替わる。ゲームパッドをつなぐと「GAMEPAD CONNECTED」。
- カメラは小さな球として壁・岩・建物・青い根・地形・天井との当たりを調べ、間に何かあればすぐカーボン側へ寄り、なくなったらゆっくり戻る。

## 素材・元素の見せ方
- 初めて手に入れた素材：画面中央に大きなカード（ゆっくり回る3D・NEW・名前・×数）。2回目からは小さな「＋ 名前 ×1」。
- 初めて理解した元素：UNDERSTOOD カード（元素の3Dイメージ・記号・原子番号・英語名・日本語名）。元素は「拾う」のではなく「理解する」。
- 持ち物：サムネイル付きの一覧。選ぶと大きなプレビュー（指・マウスで左右に回せる。触っていない間はゆっくり自動回転）。
- 図鑑：理解した元素を選ぶと、3Dイメージ・記号・原子番号・名前・本物の科学・ゲームの能力。3Dは「ゲーム上のイメージ」と明記。
- 3Dビューアは `src3d/ch1/itemViewer.ts` の1つだけ。表示していない間は描画しない。サムネイルは一度だけ画像にして使い回す。
- 見た目の指定は `materials.ts` の `visual`：`model`（GLB）→ `icon`（PNG、`public/assets/items/`）→ `proc`（コードで作った仮3D）→ 文字のみ。
- 初入手の記録はセーブの `seen` / `seenEl`（古いセーブは、持っている物・理解済みの元素を「見た」として読み込む）。
