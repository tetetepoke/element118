## 複数の解き方
- **緑の岩くず**：SiC FORM の HARD BREAK、または青銅のハンマー（棒＋青銅のかたまり）。
- **ロクショウムシ**：SiC FORM で押し通る（虫がはね返る）、または平らな石の台に銅を置いておびきよせる（45秒）。
- **発電所の切れ目（2か所）**：それぞれ「銅線」「キュプラに立ってもらう」「Cu LINK のカーボンが上に立つ」のどれか。最低1本の銅線が必要。
- **スズと青銅**（寄り道）：砂錫の沢の黒い砂＋炭→スズ（Sn を理解）、銅＋スズ→青銅、青銅→青銅の刃。

## 新しい元素・物質（白＝本物の科学、緑＝ゲームの設定）
| | 種類 | 本物の科学 | ゲーム |
| --- | --- | --- | --- |
| 孔雀石 Cu₂CO₃(OH)₂ | 鉱物 | 銅をふくむ緑の鉱物。炭と熱すると銅が取れる | 緑の坑で取れる |
| 炭 | 材料 | 木を酸素の少ない所で熱すると炭素の多い炭が残る | 窯で棒1→炭2 |
| 銅 Cu | 元素 | 電気・熱をよく通す。のびやすく線になる | Cu LINK（キュプラとつながる） |
| 緑青 | 混合物 | 銅が空気中の水分・二酸化炭素などと反応した緑のさび | 洞の岩肌 |
| 錫石 SnO₂ / スズ Sn | 鉱物 / 元素 | 重いので川底にたまる（砂錫）。スズは約232℃でとける | 寄り道 |
| 青銅 | 合金 | 銅＋スズ。銅よりかたい | ハンマー・刃の材料 |
| 古い光の板 | 材料 | ケイ素は光を電気に変える部品（太陽電池）に使われる | 根の光で発電（架空） |
| ロクショウムシ・ヒカリクイ | 生き物 | （本物にも銅をふくむ血の生き物がいる） | 架空の虫 |

Cu LINK は「炭素（黒鉛）も電気を通す」ことをモチーフにしたゲームの能力。銅と炭素の化合物ができるとは言っていない（ゲーム内でも明記）。
